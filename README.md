# ✿ BlossomRanks

Kill ranks for Blossom SMP (Paper 1.21.11). More player kills = higher rank.
Works next to RankedSMP. Uses Vault (BlossomEconomy) for money rewards and
PlaceholderAPI for scoreboard placeholders - both optional.

- `/killranks` - see every rank and how close you are
- `/killranks reload` - reload config (permission `blossomranks.admin`)

Placeholders: `%blossomranks_rank%`, `%blossomranks_kills%`,
`%blossomranks_next_rank%`, `%blossomranks_kills_needed%`
